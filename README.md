# Misskey 小画面キット

小さいスマホ（Jelly Starを想定）用に調整した Misskey のカスタムCSSです。

- アイコン類を小さくする
- アイコン下の余白を無くす
- フッターやドロワー類の余白を詰める
- サーバー切断の警告を非表示に
など。

## 使い方

1. [`small-screen.css`](small-screen.css) を開いて全文コピーする
2. 使っている端末の Misskey Web で **設定 → 環境設定 → カスタムCSS** に貼る
3. リロードする

保存先はそのブラウザの `localStorage`なので、スマホで使う場合はスマホで貼ってください。

Misskey のバージョンや画面構造が変わると、セレクタが外れることがあります。本番の Vue CSS Modules クラス名はバージョンで変わるので、公式のグローバルクラス（`._spacer` / `._button` / `._modalBg` / `._popup` / `._noSelect`）と構造で当てています。

## Misskey側の設定
- デバイスタイプ（設定→環境設定→全般）の設定はスマホ
- フォントサイズ（設定→環境設定→アクセシビリティ）は下から二番目

絵文字パレット（設定→絵文字パレット）の
- サイズ大＋＋
- 列５
- 高さ大＋

などを想定しています。
その他、設定によって合わないかもしれません。

## 壊れたとき（セーフモード）

カスタムCSSで画面が操作できなくなったときは、Misskey 公式の **セーフモード** で入り直します。URL の末尾に `?safemode=true` を付ける、または起動エラー画面の「セーフモードで起動」を使います。

セーフモードではカスタムCSS・プラグイン・独自テーマが無効になります。入ったらカスタムCSSを消すか直して、画面上の「オフにする」で通常起動に戻してください。

[セーフモード | Misskey Hub](https://misskey-hub.net/ja/docs/for-users/features/safemode/)
